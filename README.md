# The Binary Architect
Personal blog built with plain HTML + JS, hosted on GitHub Pages.

## My Personal Blog
I write about a variety of things. I initially wanted to create a website, but realized, "Git" is very useful for handling the history.

## Adding a post

1. Create a file in `blog/` named `MM-YYYY_Title.html`
2. Include a keywords line somewhere in the post body:
   ```
   keywords: tech, writing
   ```
3. Finally, Add the path to the `POSTS` array in `index.html`
